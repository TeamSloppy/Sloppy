## Предложенная стратегия интеграции

Рекомендация: additive API и компоненты сначала, подключение инструментов в последнем PR. Это позволяет обойтись без временного feature toggle. Регистрация tools и выдача скилла выполняются после готовности трёх клиентов.

Альтернатива для раннего пилота: временный выключенный по умолчанию флаг только в точке выдачи UI-tools агенту. Это даёт живую проверку раньше, но потребует отдельного PR удаления флага после общего включения. Текущая карта рассчитана на первый вариант; изменение стратегии согласовать до реализации.

Каждый срез проверяется узкими тестами и соответствующими CI-командами. Перед открытием PR измеряется фактический размер diff. После слияния пересматриваются оценки и границы оставшейся работы. Создание, публикация и слияние PR — отдельные действия, не выполненные этим планированием.

## Следующие продуктовые итерации

Таблицы/фильтры, графики, локальные вычисления, прямые действия, workspace-закрепление и внешний ACP не входят в v1. Для каждой итерации сначала определить пользовательский сценарий, одинаково доступное действие на трёх клиентах и совместимость каталога, затем составить собственные небольшие срезы.


## Ход реализации

- 2026-10-27: начало PR 1 от актуального `origin/main` (`0d8fd03d`), ветка `codex/a2ui-session-surfaces`, отдельный managed worktree. Незакоммиченные изменения основной рабочей копии сохранены.
- Срез ограничен Text/Column snapshot, обратно совместимым полем сообщения и read API журнала. Производитель и клиенты пока не включаются; временный feature toggle не требуется.
- Пакетные проверки: round-trip JSON, версия/каталог, metadata, shape компонентов, циклы/ссылки/глубина и ограничения размера. Core-проверки: независимое чтение журнала, пересоздание сервиса, последняя валидная ревизия, изоляция сессий, 400/404 и legacy-text fallback.

- Первый срез: исходный коммит `136ad4c9`, ветка `codex/a2ui-session-surfaces` отправлена в `TeamSloppy/Sloppy`; 353 reviewable lines кода/тестов. Документация и generated lockfile hash исключены из этого числа.
- Успешно: SloppyA2UI — 4 test functions / 19 cases; профильные Core/session — 14 tests, включая все новые A2UI-тесты; macOS release-сборки `sloppy` и `SloppyNode`; CLI smoke (`sloppy --version`, `SloppyNode --help`); license compliance и diff whitespace check.
- Полный `swift test --parallel --skip-build` не зелёный: запуск остановлен по лимиту 180 секунд после 74 зарегистрированных issues в 21 файле. Все A2UI-тесты прошли и в нём. Есть сбои path/tool, relay/HTTP, terminal/runtime и других проверок. Сравнение с чистым main не выполнялось; эти ошибки не объявляются доказанно существовавшими до среза. Linux/Windows и клиентский UI локально не проверялись; production не менялся.
- Первоначальное создание Draft PR было отклонено автоматической проверкой. После прямого разрешения пользователя итоговый коммит отправлен и Draft PR #74 создан; подробности — в следующем разделе.
- Следующий срез карты — публикация `ui.catalog`/`ui.render` и сохранение валидных A2UI-обновлений. Не включать доступную агентам генерацию, пока renderer общего каталога не готов во всех трёх клиентах.

- 2026-10-27: получено прямое разрешение отправить итоговый коммит, создать Draft PR в TeamSloppy/Sloppy и продолжить следующий срез. Итоговый коммит отправлен; [PR #74](https://github.com/TeamSloppy/Sloppy/pull/74) создан как Draft и прикреплён к чату. Прежний отказ на создание этого PR снят новым явным разрешением.
- Текущая ветка — `codex/a2ui-publishing`, база — `codex/a2ui-session-surfaces` (`b2d12564`). Это зависимый срез; main и первый PR не изменяются. До слияния #74 его отдельный diff рассматривается относительно первой ветки.

- Размер среза 2: 567 reviewable lines кода и тестов относительно базы первого среза; документация не учитывается. Временные feature toggles и внешний runtime не добавлялись.
- Общий прогон среза 2: `swift test --parallel --skip-build` остановлен по 180-секундному лимиту; до остановки зарегистрированы 63 issues в 18 файлах. Все A2UI-тесты прошли и в этом запуске. Полный набор не объявляется зелёным; сравнение с чистым main не выполнялось. Release-проверки идут отдельно.

- Контрактные тесты SloppyA2UI включены в корневой `swift test` отдельным target `SloppyA2UIContractTests`, чтобы CI-команда не пропускала тесты локального dependency package. Финальный профильный прогон — 22 tests, включая 7 пакетных функций / 33 cases.

- Итог среза 2: macOS release-сборки `sloppy` и `SloppyNode` прошли, включая повторную проверку после подключения корневого тестового target. CLI smoke (`sloppy --version`, `SloppyNode --help`), license compliance и whitespace check прошли. Новых внешних dependencies нет. Клиенты и production не менялись.
