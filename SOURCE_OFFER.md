# Corresponding Source for Sloppy Community

Sloppy Community releases provide their Corresponding Source at
[github.com/TeamSloppy/Sloppy](https://github.com/TeamSloppy/Sloppy).

For an official binary release, use the source archive or Git tag with the same
version as the binary. The release page contains GitHub-generated source
archives, and the matching tag contains the build scripts, Dashboard sources,
license texts, and other material needed to rebuild that release.

The release version can be printed with:

```console
sloppy --version
```

`AGPL-3.0-only`; see [`LICENSE`](LICENSE) and the
[license map](LICENSES/README.md). Public SDK and native-client paths listed in
that map are MIT licensed.

If you modify Sloppy and let users interact with the modified program over a
network, AGPL section 13 requires offering those users the Corresponding Source
of the version they are running. If you redistribute binaries, you are
responsible for preserving notices and satisfying all applicable source-code
obligations for your build.
