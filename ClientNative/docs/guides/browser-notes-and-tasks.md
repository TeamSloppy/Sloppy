# Notes and personal tasks

On macOS, use the icons at the bottom of the Browse sidebar: **Sites (Cmd+1)**, **Time & Focus (Cmd+2)**, **Tasks (Cmd+3)** and **Notes (Cmd+4)**. Switching changes only the sidebar; the current website stays open beside it. Drafts, searches and the selected note remain in place when switching modes. On iPhone and iPad, open Notes or Tasks from the browser menu.

These are personal, device-local tools. They work without a Core connection and are separate from project tasks stored on a server. They do not sync through iCloud browsing history.

## Notes

Create a note, enter its title and write Markdown in the editor. Changes save automatically, including untitled drafts. **Preview** renders headings, links, lists and code blocks. Markdown checkboxes such as `- [ ] Ship release` can be clicked in Preview; changing them updates the original Markdown. Checkbox examples inside fenced code blocks stay literal.

Use the note actions menu to pin a note, attach the current page, create a task from its title and body, export a `.md` file or delete the note. Opening an attached page creates a new browser tab. Search matches titles, Markdown content and attached URLs. Pinned notes appear first, followed by the most recently edited notes.

## Tasks

Enter a title and choose **Add** for a quick task. Choose **Details** to add a description, due date and time, priority, or current-page link. Select an existing task to edit it. The editor saves only when you choose **Save**; **Cancel** discards draft changes.

The active list groups tasks by Overdue, Today, Tomorrow, Upcoming and Anytime using the device calendar. **Today** also includes overdue tasks. **Upcoming** shows tomorrow and later dates. Use the completion circle to finish a task; **Completed** lets you reopen it. Linked pages open in a new tab. Deleting a task or note requires confirmation. Due dates organize tasks; they do not schedule notifications.
