# Favorites

In Browse’s Sites sidebar, **Favorites** sits above **Tabs**. Right-click an open tab and choose **Pin to Favorites**, or use the plus menu beside Favorites to pin the current page. The existing page moves into Favorites without reloading or losing its form state.

Favorites are saved on this device. Closing a pinned page keeps its saved favorite; selecting it again opens its pinned address. If its page is still open, selecting the favorite brings that same tab forward. Pinning the same address again reuses its existing favorite.

## Folders

Use **Favorites → + → New folder** to create a folder. A folder’s context menu can create subfolders or pin the current page directly inside it. **Pin to Favorites folder** on an ordinary tab can also pin selected tabs into an existing or new folder.

Right-click a saved page or folder to rename it or choose **Move to folder**. Move to **Favorites** to return to the top level. Folder choices exclude the folder itself and its descendants. Expansion state, hierarchy and order survive restarting Sloppy. Items can be reordered within their current level using the list’s native reorder interaction; moving between folders is available through the context menu.

**Unpin from Favorites** keeps an open page as an ordinary tab, including its form state and original tab group. **Remove folder (keep contents)** moves its contents into the parent rather than deleting the saved pages. Existing bookmarks remain available from the browser menu.
